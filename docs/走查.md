# 十分钟走查

这条命令起好页面，并写入一版做法和一页开盘安排：

```bash
./demo.sh
```

名字叫 **涨停回马枪**。地址里的 `v46-huimaqiang` 是这只对象的编号，不是另一套做法。

## 看什么

1. 打开 http://localhost:5173/workshop/pre-open?date=2026-10-15  
   这是演示账户在 2026-10-15 的开盘安排。页首是「还没写下委托」。它指着涨停回马枪这一版。

2. 打开 http://localhost:5173/ontology/object-view?type=Strategy&id=v46-huimaqiang  
   图中间是「这一版」。点 **牛市**：赚到 4% 才跟踪，回落 3% 就卖，最多拿 7 天、5 只、单只 20%。点 **计算包**，进到挑股票的函数。

3. 打开 http://localhost:5173/ontology/manager?section=function&type=computeHuimaqiangFactors&kind=function  
   点 **涨停过**：近 20 日至少 1 次，近 60 日不超过 5 次。

4. 打开 http://localhost:5173/course  
   课程把同一条线收成可以点的章节。

登录用 `admin@example.com` / `admin123`。这组账号只在本机开发模式里生效。

## 这页上有什么

| 你点的 | 它是什么 |
| --- | --- |
| 开盘安排 | 明早这一页。属于哪个账户、哪一天、用的哪一版做法 |
| 涨停回马枪 | 一版钉死的数。改一处是新的一版 |
| 涨停过、回落一截 | 函数里的挑选顺序，不写在做法对象上 |

行情大文件不在这个仓库里。这条 demo 只有这一版的数和一页安排，没有一整天的行情。
