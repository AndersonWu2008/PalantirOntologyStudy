## 数据阶段

| 闸门 | 怎么过 |
|------|--------|
| 主键唯一 | ticker；ticker:date；strategy:date:ticker |

## Foundry 平台校验（对应官方 pipeline 实践）

- Dataset health checks / data expectations。
- Ontology 映射后抽样：对象数 = 干净表行数。
- Schedule 失败告警；失败日不产生「完整」Signal。
- Action 权限：trader vs viewer。
- 分支：改 Function 在 branch 验证再合入主 Ontology。
