# 13 — 分类总表

推演中出现过的东西，全部落在五种 Ontology 类型或 Pipeline/Source。没有「暂时放 Excel」。

## Object type

Stock，Company，Exchange，Industry，Index，TradingDay，DailyBar，Account，Strategy，Signal，Order，Fill，Position。  
可选后期：StrategyEvaluation。

## Property（摘）

| 对象 | 源 | 派生 | 决策 |
|------|----|------|------|
| Stock | ticker, name, board, ST, 股本, 上市日 | memberCount 不在 Stock 上 | 紧急 ST 覆盖（罕见 Action） |
| DailyBar | OHLCV, 额, 换手, 涨跌停价, sessionComplete | 09_indicators 全部指标 | 无 |
| TradingDay | sessionDate | breadth, regime, streak, 涨跌家数 | 无（默认） |
| Signal | 键里的日期代码 | score/rank/dd/… 快照 | status, reason |
| Position | — | 建议止损（可快照） | 股数、入场价、regimeAtEntry、status |
| Order | — | 建议股数快照 | 状态、限价 |
| Strategy | version, 参数 struct | — | enabled |
| Account | 账户号 | — | cash, tradingPaused |
| Fill | 成交价量时间 | — | — |

## Link type

issuedBy，listedOn，inIndustry，parentIndustry，constituentOf，hasDailyBar，barOnDay，signalForStock，signalOnDay，producedBy，positionOf，heldIn，openedBy，orderForStock，placedIn，fillOf，fromSignal。

## Action type

ApproveSignal，RejectSignal，SubmitBuyOrder，SubmitSellOrder，CancelOrder，ClosePosition，ReducePosition，PauseTrading，ResumeTrading，EnableStrategy，DisableStrategy，MarkSpecialTreatment。  
可选：AddToUniverse，OverrideRegime（极稀有）。

## Function

computeOverlays，computeAllFactors，computeTurnoverDynamics，computeLiveRanks，computeBreadth，detectRegime，gateOpen，isLimitUp，limitBand，scoreV2，rankUniverse，filterUniverse，sizePosition，preTradeRisk，suggestedStopPrice，trailingStopHit，maxHoldExceeded，industryNameCount，industryNavWeight，dailyDrawdown，evaluateStrategy，inTradableUniverse。

## 不是 Ontology 类型

行情 Source、原始/清洗 Dataset、Schedule、Workshop 模块、券商网关、pickle、Excel。
