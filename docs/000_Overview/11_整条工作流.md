# 11 — 整条工作流

日频与周月是两条 Schedule，共用一套 Ontology。

## 日频（每个 A 股交易日）

```
15:00 收盘
  → Pipeline：同步日历、证券、K 线、行业、券商成交
  → 校验：池内 ticker 到齐 / sessionComplete
  → Function：overlays → 全部因子 → 换手动态
  → Function：computeLiveRanks（456 截面）
  → Function：computeBreadth → detectRegime
  → Function：rankUniverse → 写入当日 Signal 对象
  → Function：对每个 open Position 算建议（止损/到期）
  → 操作员在 Object Explorer / Workshop：
        读 TradingDay、Signal、Position
        Action：Approve / Reject / Close / SubmitBuy / Pause
T+1 09:30
  → 委托进券商
  → Fill 同步回 Ontology
```

中间计算全部来自源 DailyBar + 已有 Position，**没有**「表里写死的明日推荐股」。

## 周月

```
评估窗口结束
  → Function evaluateStrategy（无前视）
  → 人看报告
  → Action 改 Strategy 或切换 enabled
  → 下一交易日日频自动吃新参数
```

## 对象在时间里怎么长

| 时间 | 新增/更新 |
|------|-----------|
| 一次全量历史 | 456 Stock + 多年 DailyBar + TradingDay |
| 每个交易日 | 456 DailyBar + 1 TradingDay + N Signal + 账本 |
| 每次下单 | Order / Fill / Position |
| 每次迭代 | Strategy property 或新 Strategy 对象 |
