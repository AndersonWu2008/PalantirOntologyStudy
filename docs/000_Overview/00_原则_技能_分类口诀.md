# 00 — 原则、技能、分类口诀

在推演「明天买什么」之前，先把**不许跳过的规矩**写死。后面每一章末尾都要回到这里打勾。

## 1. 第一性原理（本系统只认这四句）

1. **数字孪生是市场与账本，不是 Excel 的影子。** Ontology 描述真实世界里的股票、交易日、持仓、订单。数据集是孪生的底座，不是用户工作语言。
2. **每种数只有一个真相来源。** 收盘价来自行情源；MA20 只能由收盘价序列算出来；「已批准」只能来自人/Agent 的 Action。禁止第三处手填同一含义。
3. **计算不是决定，决定必须被捕获。** 算分、算制度、算仓位是 Function（或 pipeline 调用同一公式）。真正改世界（下单、暂停、启用新策略版本）是 Action。Palantir 称之为 decision capture。
4. **自动化用 Pipeline，决策用 Action。** 每晚重算 45 个因子不是 Action（Golden Hammer 反模式）。把算好的分数**批准成明天的指令**才是 Action。

## 2. Foundry 分层（从上往下是使用，从下往上是建设）

```
Workshop / Object Explorer     人看见「股票」「信号」并点 Action
        ↑
Ontology  (object / property / link / action / function)
        ↑
派生写入   pipeline 或 function-backed action 把公式结果写成 property
        ↑
清洗数据集  Code Repository / Pipeline Builder
        ↑
原始数据集  Source sync（行情、行业、账户成交）
        ↑
外部世界    交易所、行情供应商、券商
```

建设顺序是**自下而上**（12 章）。理解顺序是**自上而下**（01→10 章）。两套顺序都要走完，缺一就会在表结构和按钮之间来回拧。

## 3. 三类 Property（必须分清）

| 种类 | 谁写 | 例子 | 能否手改 |
|------|------|------|----------|
| **源 Property** | Pipeline 从外部事实同步 | `close`、`ticker`、`name`、成交回报 | 否。错了回源头修 |
| **派生 Property** | Function 的唯一公式；无人值守时由 **Schedule 调同一 Function/transform 写回** | `ma20`、`factorMom1m`、`regime`、`scoreV2` | 否。改公式再跑，禁止填常数当真相 |
| **决策 Property** | Action 写回 | `Signal.status=approved`、`Order` 新建、`tradingPaused` | 是。这是人的意志 |

「Function + Action 更新派生 Property」在本教程里的精确含义：

- **日频无人值守：** Function 是唯一公式；**Pipeline Schedule** 执行公式并写派生 Property。这里没有交易员 Action。
- **要把计算结果变成可审计的业务对象时：** Function 算出建议，**Function-backed Action** 把建议固化到 Signal / Order（仍记录公式版本与输入对象）。这是决策快照，不是第二套算法。
- **查询时派生（Foundry derived properties）：** 如 `gateOpen`，不落库，每次用当前 Strategy 参数现算。参数一变，历史日的门控解读跟着变；若需要「当时门控是关的」则在 Signal 上做决策快照。

## 4. 每一步停下来的分类口诀（五问，碰到「是」就停）

1. Object Explorer 会**搜这个名字**吗？→ **Object type**
2. 它只是某个已有对象上的一个值吗？→ **Property**（再标：源 / 派生 / 决策）
3. 它是两个可命名对象之间的关系吗？→ **Link type**
4. 有人（或 Agent）在**提交一次改 Ontology** 吗？→ **Action type**
5. 它是一段**可读对象、可重跑**的逻辑吗？→ **Function**

补充：无人值守、确定、可调度 → **Pipeline**（不是 Ontology 五种类型之一，但是 Foundry 的第六个工具）。

具体闸门见 [14](./14_技能与校验清单.md)。这里只记**何时打开哪本**：

## 6. 每一步默认校验（没过不许进入下一推演）

1. **唯一键：** 该对象类型的主键在全库唯一（Stock=`ticker`，DailyBar=`ticker:date`）。
2. **血统：** 每个派生 Property 能指出 Function 名称、输入对象、能否重算对齐。
3. **市场范围：** 出现的代码都是沪深 A 股；没有 GICS、美元、美股交易所。
4. **反模式扫描：** 有没有把因子挂在 Stock 上、有没有用 Action 算 MA、有没有 `Stock_20261009` 这种类型。
5. **可搜索性：** 操作员能用一句话在 Object Explorer 里找到这一步的产物。
