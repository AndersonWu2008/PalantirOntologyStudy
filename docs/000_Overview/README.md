# 从零到一：用 Palantir Ontology + Foundry 搭 A 股交易系统

这是一份**教程**，不是类型清单。类型清单在 [`../000_Stock_Object_Type/`](../000_Stock_Object_Type/README.md)。写法受 [`../000_Guideline/`](../000_Guideline/README.md) 约束：先澄清核心输出（买入、卖出），再补全，再用人话追问输入，最后才落类型。与手册冲突时改本目录。

读法：**从最终目标往回推**（本目录 01→10），再 **从零往前搭**（12）。中间每停一步，都用同一套分类口诀和校验。思考过程原文在 [15](./15_思考过程全记录.md)，不要跳过。

## 最终目标（一句话）

收盘后把**当日可下载的交易数据**和**已入库的历史**合在一起，得到**明天开盘要执行的策略**（持什么、买卖什么、还是空仓）；并且**每周/每月**用同一套 Ontology 上的历史，迭代策略版本，而不是另起一套表。
