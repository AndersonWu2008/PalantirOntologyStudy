# 08 — 股票池与参考数据

## 思考

456 不是宇宙里所有 A 股。它是 **Index** 的成员集合，由 `filterUniverse` 规则从更大的证券列表筛出。

规则在 `data_pipeline/universe.py`：价格区间、市值、换手三层、上市满 200 日、排除科创/北交所/新三板、ST 等。

这些规则是 **Function**。成员关系是 **Link** `constituentOf`。不要在 Stock 上堆 `inPool=true` 却无法回答「哪个池」。

池子会变（每周迭代可能重筛）。变更方式：

- 无人值守：Pipeline 跑 `filterUniverse`，diff 后增删 link。
- 人工纳入/剔除：Action `AddToUniverse` / `RemoveFromUniverse`（决策，须写 reason）。此后日频广度分母跟着 link 走。

## 参考数据清单（源）

| 数据 | 落点 |
|------|------|
| 证券列表 | Stock |
| 法人公司 | Company + `issuedBy` |
| 上交所/深交所 | Exchange + `listedOn` |
| 行业树 | Industry + `parentIndustry` + `inIndustry` |
| 交易日历 | TradingDay |
| 核心池 | Index `ashare-core-456` + `constituentOf` |

没有这些，07 的 K 线下载没有 ticker 列表，05 的广度没有分母。

## 停：分类

| 事物 | 判定 |
|------|------|
| 456 只这一组 | Object type **Index** + 456 条 **Link** |
| filterUniverse | **Function** |
| 人工调入池 | **Action** |
| 主板/创业板 | Stock **源 Property** `board` + value type |
| GICS Sector | **不建** |

## 校验

Index 成员数应可核对（文档写 456 则以当时 snapshot 为准，变更后更新 Index 的说明 Property `asOfDate` + `memberCount` 派生）。广度分母 = 当日仍为成员且有完整 bar 的数量。
